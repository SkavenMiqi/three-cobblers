# TalkApp 产品方向（用户选择确认）

## 定位

自用安卓个人 AI，保留现有黑钛界面。以一个长期助手为核心，覆盖日常陪伴、学习工作、图片问答和语音聊天，可切换任务模式。

## 最新语音纠正

用户明确需要连续语音对话，而非看完文字后的朗读。撤下朗读配置与逐消息朗读菜单，不自动朗读文字聊天。后续以单一语音入口进入连续对话界面，包含听取、思考、回答状态、停止/退出与打断能力。优先评估现有服务商实时音频接口；不支持时采用转写→聊天→语音合成的连续会话链路，不能把已有转文字按钮宣称为实时语音已完成。

## 最新记忆决策（覆盖后文早期选择）

再次修订：长期记忆参考 Hermes 的精简笔记/用户画像与历史会话检索双层机制。每段对话由模型判断是否值得记忆，短对话也处理；10000字→50字为压缩比例而非触发门槛。无价值内容跳过，自动维护、隐藏运行。

用户取消确认式个人记忆。未删除对话每累计约10000字符，后台生成约50字内部摘要，供后续对话参考；无需确认，不展示摘要、来源或管理入口。不足阈值先累积。删除对话同时删除其内部摘要；按选中分支匹配，避免混入废弃版本。受上下文预算限制，优先近期摘要。

## 已确认的选择

- 语音：争取接近 ChatGPT 的自然连续交流；实时接口需另行评估。备选为语音输入与自然朗读，调研开源中文语音方案。
- 语音部署：允许电脑辅助运行开源语音模型；电脑不可连接时，手机系统朗读兜底。
- 记忆：AI 提出候选记忆，经用户确认后保存；用户可查看、修改、删除。与原始历史及会话摘要分开管理。
- 联网：自动判断是否搜索，同时提供手动开关，回答附来源。
- 阅读：图片（拍照/相册/多图）、PDF、文档、网页均需要。
- 历史：本地保存，支持自动加密备份。备份目的地及恢复密钥方案待定。
- 优先级：先打牢聊天基础，再逐步实现其余能力。
- 消息版本：编辑旧问题或重新生成回答时保留分支，可切换查看原内容。
- 模型使用：一个默认模型；允许在同一对话的当前分支手动切换，每条回答记录服务商与模型来源。
- 历史交互：从现有菜单打开侧边栏，提供搜索、新建、置顶和日期分组，保留主界面黑钛风格。
- 长对话：按模型预算自动摘要较早内容，保留近期原文；摘要可查看和重建，原始历史完整保留，按分支隔离。
- 交付节奏：聊天基础功能整批实现并验证后，一起体验。

## 下一轮范围：聊天基础

1. 消息状态：发送、生成、完成、失败、取消；保存已收到的部分，失败可重试。
2. 消息操作：编辑后重新提问、重新生成、复制与删除；明确编辑后后续上下文如何处理。
3. 阅读和输入：Markdown、代码块复制、多行输入；用户向上阅读时不强制滚回底部。
4. 历史管理：搜索、自动标题、置顶；原始历史完整保留。
5. 长对话：按模型预算管理上下文，摘要独立保存，可追溯原文。
6. 手机体验：验证键盘、滚动、后台切换、图片和长回答。

## 后续路线

文字侧整批实现状态已整理至 `docs/delivery-status.md`，以该文档为准区分完成、需配置和待真机验证。已加入加密备份、临时对话、多图/相机入口、Markdown导出和代码高亮。语音按用户要求暂停，真实全双工与开源自然音色不列入已完成。
