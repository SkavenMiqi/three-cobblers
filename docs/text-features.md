# 文字侧本轮功能

## 入口

- 输入栏 `+`：选图片、选文件、预览/移除附件。
- 顶部 `⋮ → 联网与后台模型`：联网自动/强制/关闭，Tavily密钥、后台模型ID、主模型输入输出单价。
- 顶部 `⋮ → 调用用量`：按任务和模型统计调用次数、输入输出token。
- 回答 `⋮ → 查看网页来源`：打开本次读取/搜索的链接。
- 历史搜索点击结果：切换至匹配的消息分支，并滚动至匹配消息。

## 费用

没有配置后台模型时，标题、记忆、摘要仍使用主模型；可以填写同一服务商上可用的便宜模型ID，所有后台任务统一路由至它。
不自动更换用户主聊天模型。后台模型单价未配置，因此后台调用只统计token，不冒用主模型单价估算。
服务商返回usage时记录已报告token；未返回时用保守近似估算，明确标为未报告。只有已报告用量且填写单价时才估算费用，实际账单以服务商为准。缓存命中等特殊计费未细分。失败请求的估算不能证明实际扣费。
防止同一进程中前台补摘要与后台整理对同一块重复运行；后台仍会产生额外调用。

## 联网

自动模式采用本地时效/搜索关键词规则判断，不额外向大模型发判断请求。强制模式每次搜索；关闭模式不读取网页。
搜索目前接入Tavily，需要独立密钥和相应额度，尚未配置真实密钥联调。
直接粘贴公网网页URL可以读取静态HTML，不需要搜索密钥；受登录、反爬、动态页面影响可能失败。不会绕过访问限制。
网页资料附标题和URL，要求模型标注来源；界面保留实际来源链接。来源引用质量仍需真实模型测试。

## 文件

支持有文字层的PDF（标注页码）、DOCX、TXT、MD、CSV、JSON、PY。
每次最多3个文件，单文件小于12MB，提取上限12万字符。长文件按关键词选节后发给模型，明确标为节选，不保证全文覆盖。
扫描PDF需要OCR，暂未接入；不支持老式二进制DOC。
原始文件不复制到历史，只保存提取文字和文件名。附件随消息分支保存，删除消息后级联清除。编辑问题保留附件。
Android 系统文件选择器已接入，但文件库打包与真机读取尚未验证。

## 验证

单元测试覆盖真实DOCX提取、PDF空白页拒绝、文本选节、网页/搜索接口模拟、usage解析、附件分支删除。
界面流程使用隔离测试数据库和模拟模型，没有消耗个人聊天API验证。未生成APK。
