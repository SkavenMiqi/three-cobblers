# 当前交付范围

## 已实现并有本机验证

- 黑钛聊天界面、紧凑菜单、消息时间、历史更新时间。
- 多行输入、流式文本、复制、编辑问题/重新生成分支、失败重试、停止/关闭保存部分输出。
- 标题生成、历史搜索定位、置顶、重命名、删除、当前分支Markdown导出。
- 模型配置与切换、每条回答模型来源；同服务商后台模型分流。
- 调用次数与token统计；区分服务商报告/本地估算；填写单价后估算金额。
- 自动隐藏长期笔记＋关键词历史回忆、按分支隔离，删除对话清除其笔记。
- 长对话上下文摘要，正文留存。
- 临时对话不进入记忆/检索/备份，离开和应用重启清除。
- 最多4张图片、图片预览放大，最多3个文件；PDF文字层、DOCX和文本提取与节选问答。
- 静态网页正文读取、Tavily搜索接入、自动关键词/强制/关闭模式、实际来源链接。
- Markdown标题、列表、表格、代码高亮/复制、可点击链接。
- AES-256-GCM + scrypt口令加密备份、本地轮换、WebDAV上传、备份文件恢复；包含历史、图片数据、提取文件文字、内部笔记和主要配置。
- 前后台切换保存流式进度，语音退出/暂停清理资源。

## 需要一次性配置

- 搜索：Tavily密钥，当前未配置实际账号。
- 备份：选择本地目录和/或已有WebDAV目录，设置并自行保管口令。默认不开启，不能替用户生成一个不可恢复的口令。
- 后台模型：填写服务商实际可用模型ID；留空沿用主模型。
- 单价：以自己服务商实际计价填写，统计不替代账单，缓存/阶梯计费未细分。

## 自动备份的真实运行边界

应用启动、运行中每5分钟、恢复前台、回答完成时检查是否达到设定间隔。此版本不是Android后台常驻服务；应用被杀死时不会唤醒备份。
本地保留份数自动轮换，WebDAV远端不自动删除旧备份。恢复入口读取用户选择的备份文件；远端文件需先下载到设备。
口令和WebDAV认证保存在应用私有设置文件，尚未Android Keystore保护。备份文件本身使用认证加密。备份配置不放进备份，避免把恢复口令和加密内容放在一起。
恢复覆盖现有历史和主要设置，先在临时位置解密校验；不是合并导入。

## 已接入但尚不能宣称验证完成

- Android相机、文件选择、多图、TTS、录音、生命周期：代码已接入，需要真机。拍照直连入口支持Android10+，更老设备可相册选图。
- Android包含cryptography/lxml等原生依赖，打包工具链虽已部署，最新依赖尚未完整构建验证；遵循用户之前要求，本轮没有开始打包。
- Tavily实际账户、WebDAV实际服务器未联调。测试采用模拟服务。
- PDF扫描件OCR、数学公式/Mermaid图形渲染未实现；动态/登录网页无法保证读取，长文档不是全库语义RAG。
- 跨设备实时同步未选择，只有加密备份与恢复。

CosyVoice权重、自动语音打断、低延迟双工尚未完成，当前先完成文字侧，不将这些列为已交付能力。
